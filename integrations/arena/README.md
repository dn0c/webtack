# Are.na Integration for WebTack

Connect your [Are.na](https://www.are.na/) account to WebTack to import channels, sync recent feed blocks, and synchronize AI-generated alt text.

---

## 1. Setup & Credentials

Set your credentials in your `.env` file (or export them in your shell):

```bash
ARENA_API_TOKEN="your_personal_bearer_token"
ARENA_USER_ID="12345"   # Optional: automatically resolved from /v3/me if omitted
```

---

## 2. Usage

### Import an Entire Channel
Download an Are.na channel (or import a local JSON export) into WebTack atoms:

```bash
# By channel slug or ID
python3 integrations/arena/import_channel.py visual-inspiration --limit 100

# With custom tags and collection
python3 integrations/arena/import_channel.py reading-list --collection "Readings" --tag "essays,design"
```

### Inbound Feed Sync
Pull newly added blocks across all your Are.na channels into your vault:

```bash
python3 integrations/arena/sync.py --limit 50
```

### Sync Alt Text Back to Are.na
Push accessibility alt text generated by WebTack (`python3 curate.py enrich`) back up to your Are.na blocks:

```bash
python3 integrations/arena/sync_alt_text.py
```
