# WebTack Archive Scripts

This directory preserves one-off migration, backfill, data-cleansing, and administrative scripts used during previous iterations and development phases of WebTack.

> [!NOTE]
> These scripts are preserved for historical reference, auditability, and data provenance. They are **not** needed for regular WebTack usage. All primary ingestion, enrichment, export, and disaster-recovery operations are handled directly via the core CLI (`python3 curate.py <command>`).
